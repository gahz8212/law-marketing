# 의뢰인용 프로보노 공익 지원 포털 (아카이브 보존본)

이 디렉토리는 초기에 구축된 **"외국인 노동자 및 취약계층 대상 다국어(8개국어) 음성 지원 공익 포털 컴포넌트"**를 보존하고 있는 아카이브입니다.

## 보존된 컴포넌트 목록
1. `Header.tsx`: 프로보노 공익 센터 브랜딩 헤더
2. `LanguageBar.tsx`: 8개 다국어(한국어, 영어, 베트남어, 중국어, 태국어, 캄보디아어, 우르두어, 우즈벡어) 스와이프 선택 칩
3. `ThreeStepCard.tsx`: 1단계(피해사실) / 2단계(법원판단) / 3단계(대처방안) 카드형 시각화 뷰어
4. `AudioPlayer.tsx`: gTTS 다국어 음성 스트리밍 재생기
5. `ActionFooter.tsx`: 대법원 원문 링크 및 1초 무료 공익 상담 접수 팝업 모달

## 보존 사유
회사(법무법인 정서 홍보팀)의 실제 채용 요구사항인 **"사내 마케터 업무 자동화 및 내부 도구(AX 스튜디오)"**에 집중하기 위해 메인 프로덕트에서는 분리되었으며, 향후 대외 공익 프로젝트나 포트폴리오 확장 레퍼런스로 활용 가능합니다.
